# LYRA — студия видео

Статическая демо-версия студии AI-видео на **GitHub Pages**.

- Сцена: режимы «по треку», промпт, танец, подкаст, влог
- Аватар: резиденты, загрузка фото, навыки и репетиции
- Архив и канал в `localStorage` браузера

> Реальная генерация клипов (xAI) на Pages недоступна — здесь съёмка имитируется. Для живой генерации нужен сервер (Vercel / App Builder).

## Сайт

После включения GitHub Pages:

**https://serega40in.github.io/lyra-studio/**

## Включить Pages

1. Откройте [Settings → Pages](https://github.com/Serega40in/lyra-studio/settings/pages)
2. **Source:** Deploy from a branch
3. **Branch:** `main` / `/ (root)`
4. Save

Через минуту сайт откроется по ссылке выше.
